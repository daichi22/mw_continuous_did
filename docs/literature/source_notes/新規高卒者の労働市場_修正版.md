# 第8章　新規高卒者の労働市場

有賀 健

本章では1980年代末以降の新規高卒者労働市場の急速な変化の原因を探る。学校基本調査を利用して作成した都道府県別パネルデータを用いた分析結果によれば、いわゆる失われた10年の時期を中心に3つの大きな変化が新規高卒者労働市場に起こった。(1) 就職者数と就職率の減少、(2) 府県間就職移動率の減少、(3) ジョブマッチングの質の低下、である。モデルの推定結果によればこれらの要因として大学進学率の上昇と新規高卒者の労働需要を示すが、その背景には、80年代末の大学設置基準の緩和による大学数の増加と高校在学者数の減少がある。また、90年代の経済低迷もこれら3つの変化の主要因であることが確認できる。他方、賃金の低下や高卒就職率の減少や学力低下と一見矛盾するのが、新規高卒者実質賃金の緩やかな上昇であるが、これは最低賃金や大卒初任給の上昇傾向によって説明される部分が大きい。

---

## 1. はじめに

若年者の雇用が厳しい問題を抱えており、それが90年代の経済低迷の最中に深刻さを一挙に増したことには誰も異論がないであろう。新規高卒者の就職状況の推移を見ても、90年代の変化の大きさが如実に示されている。

本章では、この変化の原因を探るため、学校基本調査を利用して都道府県別パネルデータを構築し、計量分析を行う。分析の結果をあらかじめ簡単にまとめておこう。本章で注目する大学・短大進学率と高卒就職率の意思決定を動かす要因は、1980年代末以降短期間の間に急速に大学が新設されたこと、そしてそれには同時に高卒者数の減少がある。基本として大学入学定員の制約が参加して大幅に緩和されたことである。進学率を希望する高校生の大学進学希望にかなう主な手段の不足のため進学できず、就職していた高卒者を大量に就職市場から大学へと移動させた結果となったと推測できる。本章は、この効果を直接的間接的にさまざまな側面から検証する。第1に、大学進学率の、大学数という供給要因で有意にその変化を説明できることを示す。特にこの効果は、都市圏において大きく、70年代中期から80年代後半に至るまで、大学進学率は横ばいかあるいはそれ以下であったものを90年代には、明瞭な形の緩やかな上昇となった。また、第2に、制約の緩和の効果は、すべての高卒者に及んだのではなく、就職の進路選択の意思決定において限界的な位置にある高校生に最もその効果が強かったと考えられる。それを組み入れた計量分析を行う。それによって地方の高卒者が都市圏の就職先に移動するメカニズムもその量的変化を説明できることを示す。

特に、大学進学率の上昇は、就職希望者の量のみならず質も低下させることによって、かつては就職者数と就職率を低下させただけでなく、他方では賃金水準とのマッチングを低下させ、その結果良質な職の集中する都市圏への移動率を低下させたと考えられる。

90年代の変化が大規模になったもう一つの理由はこのような供給要因の変化とは正反対に、90年代の経済低迷が始まり、その長期化により新卒者需要の量も質も急速に低下したことにある。本章の第2のポイントは、これらの需給両面要因が90年代の大きな推移を説明しうることを統計的に示すことである。計量分析の結果によれば、特に同時期の90年代の変化の説明変数として重要であるが、需要側の要因は主として実質賃金を変化させたのに対し、供給側では質変動要因でこの間の変化を説明する重要な要因であることが示される。

本章の以下の構成を簡単に示す。第2節では、90年代の変化を中心に日本における高校新卒労働市場の特徴と変化を概観する。第3節では、簡単な計量モデルを利用したデータを提示し、第4節で計量分析の結果が報告される。第5節では、結果のまとめと、未解決の問題点と今後の展望にも触れる。

## 2. 新規高卒者の労働市場の変化

すでに多くの文献により説明があるように、日本の高校卒業予定者が就職先を探す場合、彼らは一般求職者と分離される。これは、一方では地域職業安定所と個別高校の連絡相談部が協力して提供する求人案内と進路指導によって、他方では、求人先と高校卒業者を個別して採用することによって、明確な分割市場が形成されているということである。新卒者の市場は一般労働者の就職市場と区別されているといってよい。

1990年代の長期にわたる経済低迷期を通じて、このような制度的に隔離された新卒者市場は、一般の労働市場と同じかそれ以上に大きな変化を経験することになった。以下では、その変化を3つの側面から簡単にまとめてみる。

## 2.2　都道府県間就職移動の低下

第3の変化は、新卒者の県外就職率の低下である。県外就職率は高度成長期にピークを迎え、地方県で30％を超えた時期もあったが、2002年では18％にまで低下している。高度成長期には、県外求人の最も大きなシェアを持っていた製造業、さらには建設業の低下が著しい。それに代わってサービス産業の県外就職に占める比率が増加し、1972年には10％に満たなかった県外就職のうち、サービス産業への就職のおよそ3分の1になっている。

表8.1は、47県を東京・愛知・大阪の中心、それぞれの中心県の周辺県、そしてその他地方の3グループに分けて就職移動をまとめている。これら3グループの間には、新卒者の県外就職の流れに大きな差がある。中心へ流入する地方県からの就職者が中心県における就職者数を増やす一方、地方圏からの流入も存在し、全体として、やや流出が上回る程度である。地方圏では、他の地方圏との流出入が小さく、中心県と周辺県に向けて大規模の流出が見られる。

## 2.5　新卒者職業紹介の構造的な問題

高校新卒者の就職紹介の仕組みそのものや、それが抱える問題についてはすでに多くの文献があるので、ここでは要約にとどめる。

高度成長期以降に確立された就職紹介の仕組みの根幹は、個別高校と企業との間の長期関係であり、地域の職業安定所を中心とするよりオープンな紹介メカニズムではない。実際に、あまり機能せず、単にまじえては、高校側あるいは就職係の求人票の紹介も有名無実な機能が多かったとの指摘もある。いずれにしても、一般労働者への職業紹介より閉じた形で職業紹介が行われ、求人側も新卒者と申込み採用を区別して採用方針を採用学生決めることが一般的であった。

高校新卒者の職業紹介の最も重要な特徴である。このような制度的な隔離が、構造的な問題の根源にあることは確かであろう。

この就職紹介の仕組みとしてはまず企業正社員、とくに長期雇用のスキルを担い手として受け付ける。新卒者向けの求人を一般労働者向けの求人と切り離し、一般の求職者には紹介されない求人票を公開しない、という意味では、確かに新卒者に優先的に正社員・フルタイム雇用の就職先を紹介するという機能を持つ反面、新卒者に対する求人を職業の質いものにして、求人を制限した効果を持つ可能性もある。

高校間での状況も変化した。職業高校の入学希望者が減少するにつれて、多くの実業高校は、大学進学希望者向けのコースを新設したりすることで、事実上職業高校としての色彩や特徴を薄くし、普通高校への脱皮を図るものが多くなった。結果として、普通高校は無論、職業高校でも就職担当の教員は減少し、個別高校と企業との2者間関係を機軸とするような就職斡旋の仕組みを維持することは困難になっている。

## 3.　モデルとデータ

### 3.1　新卒者市場のモデル

以下で推定するモデルは新卒労働市場をサーチ市場としてとらえる。本章ではその詳細には立ち入らないが、以下で展開する実証分析は、異質性をとり入れたサーチモデルの含意と整合的なものであることを確認しておきたい。標準的なサーチモデルでは、雇用主、マッチング関数を経由して求人・求職者数により決定される。本章では、求人・求職両者の質の変化に注目するので、これらの質を表す変数をまとめる。

第1に、雇用 G がマッチングの技術的条件を体化したマッチング関数で決定される。マッチング関数の効率は、両者の間の関連性もあり、近年の低下の一要因として就職者側の質の変化を考えることができる。

第2に、求人・求職の需給関係を、利潤の最大化問題として考える。求人側は、求職者数と賃金を所与として、求人の採算に応じて求人票を出す。

第3に、求職者の進学・就職選択は、進学から得られる期待収益と、就職から得られる期待収益の比較で決まる。大学進学率の上昇は、就職希望者の量を減少させるだけでなく、就職希望者の平均的な質を変化させる可能性がある。

このモデルでは、県 i、時点 t における高校卒業者数、進学者数、就職者数、県外就職者数、求人票数、初任給などを用いて、以下の関係を想定する。

```math
G_t = C_t + E_t + N_t
```

```math
E_t = L_t + X_t
```

```math
J_t = L_t + M_t
```

ここで、卒業者は進学、就職、その他に分かれ、就職者は県内就職と県外就職に分かれる。

高校生の進学・就職選択を以下のように定式化する。最初に大学（短大を含む、以下6回同様）進学するか否かの意思決定を行う。そのあと、大学に進学しないと決定した高校卒業予定者は、就職をするか否かを決定する。そこで、大学進学者数の決定式を

$$C_t = C(G, Z_t^{PC})$$

とする。ただし $Z_t^{PC}$ は進学・就職の意思決定に影響を及ぼす外生変数のベクトルである。最適な就職希望者数 $P_t$ は、適切な就職希望者が、若者全体の就職を意識して決まると考えられる。

---

### 3.2　県外就職を含むモデル

求人側から見ると、県外高校生の中の就職希望者は県内の就職希望者と競合する求職者であり、彼らの質を明示的に扱う必要がある。

県外からの就職者には、県内高校生とは異なる移動費用や情報制約が存在する。そのため、県外就職率は、単純な求人倍率だけではなく、県内外の求人の質、賃金、進学率、地域間の需要格差によって決まる。

$$VA_t = D(Z_t^D, Z_t^{DM}) \tag{8.2}$$

県内の高卒就職希望者以外に、県外の就職希望者も対象とすることを考えると、$VA_t$ の水準を決定する要因として、県内要因 $Z_t^D$ と並んで県外高卒者に関わる要因 $Z_t^{DM}$ が考えられる。

実際の就職者数は以下のようなマッチング関数により決定される

$$E_t = \Psi(VA_t, P_t, q_t^V, q_t^P, Z_t^E) \tag{8.3}$$

ただし、$q_t^V, q_t^P$ はそれぞれ求職者と求人の質を表す変数である（質変数の定義については3.4節と3.5節で取り上げる）。同様に初任給の決定モデルを以下で示す。

$$W_t = \omega(VA_t, P_t, q_t^V, q_t^P, Z_t^W) \tag{8.4}$$

### 3.3　利用するデータ

分析で利用する中心となるデータは、文部科学省『学校基本調査』と、厚生労働省職業安定局『新規学卒者の労働市場』である。データは1962年から5年おきに2002年までの40年間、9時点のものを利用する。

都道府県水準で、新規高卒者数、進学者数、就職者数、県外就職者数、求人票数、初任給、産業別就職者数などを整理した。

ただし、データにはいくつか注意点がある。

1. **学校基本調査における就職者数**  
   卒業後に進学しながら就職している者や、進学準備中の者は扱いに注意が必要である。

2. **県内・県外就職者の定義**  
   就職先が県内か県外かは、高校所在地と就職先所在地の関係によって判断される。

3. **県内求人・県外求人の扱い**  
   求人票数は、都道府県別に集計されるが、実際には高校・企業間の長期的関係や職安を通じた紹介制度の影響を受ける。

### 3.4　就職希望者校生の質の低下

1990年代以降の新卒労働市場については、新卒者がつくことのできる職の質の低下とは別に、就職希望者の高校生の質の低下にも原因があるのではないかという議論がある。

労働政策研究・研修機構によるアンケート調査によれば、高卒求人企業の多くが、近年の高校生の基礎学力や職業意識に不安を抱いている。

とくに企業規模が大きいほど、学力・意欲・基礎的能力を重視する傾向があり、採用難ではなく、採用したい層が減少したという認識がある。

本章では、大学進学率の上昇が、就職希望者の質に与える影響を重視する。すなわち、大学進学率が高まると、これまで就職していた比較的学力の高い層が進学に移動し、就職希望者の平均的な学力や職業選択能力が低下する可能性がある。

### 3.5　求人側の質の測定

求職者側と同様、求人票を出す企業等についても、客観的な質の指標を作成する必要がある。

本章では、求人の質を直接測ることは難しいため、産業構成や企業規模、職種構成、求人倍率、初任給、離職率などを用いて間接的に把握する。

求人の質が低下すると、就職希望者にとって魅力的な就職先が減少し、就職率の低下、県外就職率の低下、離職率の上昇につながる。

### 4.1.6　まとめ

ここまでの回帰分析の結果では、一貫して「質」変数、特に求職者の質変数が、求人の変動や県外就職率、県外高卒流入、離職率などに有意な影響を与えていることが確認された。

加えて、1990年代の景気低迷による求人減少も大きな役割を果たしており、供給側要因と需要側要因の双方が重要である。

## 4.3　小括

本章では、高校新卒者市場の求人、求職、就職、さらには初任給の回帰分析を行った。結果は高卒者市場の90年代の急激な変化が、80年代後半からの大学進学率の急激な上昇、という求職者数の減少と質の低下、という供給面と、90年代のマクロ経済の低迷が大きな影響を持つものであることを確認した。それらと並んで、導出した求人・就職動機の重要な役割を担っていることが示されたこともいえ、特に県外就職率の長期的低下は、都市部の需要減少と都道府県別の大学進学率格差の縮小傾向にある程度説明できるのである。

## 5.　おわりに

本章の主張は明確である。1980年代後半以降の高等教育政策の転換により、大学新設が可能が緩和され、進学率が急速に上昇した。その結果、質量両面で高卒就職希望者が減少・低下し、それが1990年代の高卒者労働市場の急速な変化の主要な原因となった。もちろん、需要面でも求人数の減少や職種でみた大きな変化があったが、求需両面でも高卒労働市場の機能は大きく低下した。

一方、高卒初任給の相対的上昇が観察されたが、少なくとも部分的には、実質最低賃金の相対的上昇が原因の一つであったといえる。しかし、それだけでは十分に不明であり、この間の変化に関する完全な解明は今後の重要な課題として残されている。

本章の分析は概略分析に過ぎないといえるくらいに、分析結果の皮相の安さをいくつか指摘することができるだろう。大学進学率は過去40年間で2倍以上になり、60%程度にすぎなかったものが、事実上100%にちかい、日本の教育システムの成長にこれほど積極的な評価を与えるとすれば、これだけの大規模な変化が高卒就職市場に与えた影響を推定することは不可能であると推測をせざるをえない。

この観察だけでは不十分なのは、本書推定時点での当該時点では、信頼できる全国レベルの学力データでクロスセクションの分析が可能なものは事実上ない上、教育制度の変化のような分析が可能なものは個人データなしの議論が不毛である。全国レベルで長期にわたる学力調査データが何よりも不可欠である。

高校新卒者の労働市場で90年代に起こった変化は、主として構造的な要因である大学進学率が上昇したことにある。長期にわたって低下していくことにそうなるだけでなく、80年代以前の新卒雇用を支えた制度的基盤も変化しているのである。それは制度の崩壊が原因であるものではなかったし、景気の回復だけで元通りに戻るものではなく、最近年の景気回復に従って、新卒者求人が2002-03年の状況と比べてある一定の回復が見られるものになっている。景気回復の中明らかになったことは、需要の回復が非正規雇用に中心して、正社員雇用、特に高卒社員雇用については慎重な企業が目立つことにある。若年者の雇用の問題は、日本だけのものでもない。欧州ではすでに20年以上にわたり、若者雇用の不安定性や失業率が続いている。

むしろ、日本の高卒者の雇用問題のユニークさは、多くの求人企業が正社員採用、特に高卒者の正社員採用から転換を図っているのに対し、求職活動の錠となる高校と職業安定所が、依然として正社員採用の斡旋という基本路線を堅持していない点にある。市場の両面の斡旋の断絶にある。

就職率の低さや離職率の上昇に対して、就職者の支援をする高校や職業安定所の役割を大きくすることを論ずるものもあるが、本章の分析によれば、これらの根本的な原因を誤解するものといえなくも、少なくとも言過ぎである。そのような説明は間違いではないとしても、少なくとも、一方的に、地域的に大きく異なる雇用環境という背景のもとで強い変動をとくことができる。

しかし、より根本的な課題は、個別企業内での育成に委ねられていた、学校から職業への道の意識・意味での移行過程全体を、どのようにデザインし、構築していくか、という問題であろう。それは、生産のキャリアを築くには不要である、というより必要性は高くなっている。当该担当者は措くとしても、明らかなのは、高校卒業直後から定型業務も新卒社員も長期にコミットし、往々にして大きな費用をかけて人材育成を行うスタイルに全面的に依存することは、もはや不可能であるために。多くのスキルをつなぎ、職種や企業を移動しながら、技能形成が行われていく仕組みが求められる。
